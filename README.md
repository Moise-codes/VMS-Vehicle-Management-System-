# MAGERWA Vehicle Management System (VMS)

A professional full-stack Vehicle Management System designed for MAGERWA, Rwanda's public bonded warehouse.

The system provides a secure and organized platform for administrators to manage clients, vehicles, vehicle assignments, and plate numbers from a centralized dashboard.

---

## Overview

MAGERWA handles diverse cargo and requires an efficient system for recording and managing detailed information about vehicles and their associated clients.

The Vehicle Management System solves this problem by providing:

- Secure administrator authentication
- Administrator-specific data isolation
- Client management
- Vehicle management
- Vehicle-to-client assignment
- Unique plate number management
- Search and pagination
- Responsive user interface
- Protected API endpoints
- Professional dashboard
- Secure session handling

Each administrator has an independent workspace.

For example:

```text
Admin A
 ├── Client A1
 ├── Client A2
 ├── Vehicle A1
 └── Assignment A1

Admin B
 ├── Client B1
 ├── Client B2
 ├── Vehicle B1
 └── Assignment B1
```
